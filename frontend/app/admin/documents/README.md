# Module Documents Admin ✅

## Fonctionnalités
- **10+ catégories** de documents pré-enregistrés (Contrats bail/vente bien/véhicule, CNI, Immatriculation, Licence Pro, PV Assemblée, etc.)
- **Exemples pré-remplis** auto-chargés au changement de catégorie
- **Logo site** (`/logo.png`) en en-tête tous templates avec styling pro
- **Formulaire conditionnel** (immobilier/véhicule)
- **Preview temps réel** iframe
- **Download HTML** prêt-impression
- **Orthographe 100% corrigée**, templates clairs

## Utilisation
1. `/admin/documents`
2. Sélectionnez catégorie → exemple charge auto
3. Modifiez champs si besoin
4. Preview → Download/Print

Templates backend-ready (HTML interpolé).
