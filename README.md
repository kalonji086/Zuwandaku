# ZUWAndaku

Plateforme de location/vente maisons, parcelles et véhicules à Kinshasa (RDC).

## Tech Stack
- Backend: NestJS (TS) + Prisma + Postgres
- Frontend: Next.js (TS) + Tailwind

## Déploiement
- Backend: Déployé sur Fly.io (https://zuwandaku-backend-holy-glitter-298.fly.dev)
- Frontend: Déployé sur Netlify

## Quick Start
1. `npm install`
2. `npm run db:up` (Postgres)
3. Backend: `npm run dev:backend` (port 3000)
4. Frontend: `npm run dev:frontend` (port 3001)
